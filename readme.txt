1. Library being used:
pygame: for video game graphic
io: handling I/O operation
csv: saving benchmark result to be .csv file
os: handling file paths to the assets
time: calculating time executes for benchmark
queue: passing benchmark metrics and log data smoothly from background task to main display
threading: running heavy benchmark in background threads
contextlib: redirecting the log messages for the benchmark in the background
statistics: for average result in benchmark

2. IDE used: VS Code 

3. To open it:
- Clone the project to the GitHub on the desired folder,
- Open an IDE,
- Download pygame library dengan menjalankan kode 'pip install pygame' in VS Code terminal,
- Access the main.py (for the game) file,
- Run to open the application.
